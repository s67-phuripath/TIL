# Day 1: TIL Repository & Daily Compound Effect

**Category:** General / Productivity

### What I Learned Today
- แนวคิด **Compound Effect (1% better every day)** จากหนังสือ Atomic Habits
- ตั้งเป้าพัฒนาทักษะวิศวกรรมซอฟต์แวร์นอกห้องเรียนวันละ 15–20 นาที
- การสร้างและจัดโครงสร้าง TIL Repository สำหรับสะสมความรู้ประจำวัน

### Key Takeaway
"ความสม่ำเสมอในการเรียนรู้สิ่งเล็กๆ ทุกวัน สร้างความก้าวหน้าที่ยิ่งใหญ่ในระยะยาว"
